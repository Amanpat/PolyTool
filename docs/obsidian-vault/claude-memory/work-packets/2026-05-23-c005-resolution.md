# C-005 Resolution: Stale Concept/Reference Supersession Fixes

**Date:** 2026-05-23  
**Executed by:** Claude Code (Phase 3 cleanup)  
**Trigger:** Codex Phase 2 audit — C-005 was "RESOLVED (vault side)" but architecturally wrong: 42 files all pointed to `repo-docs/_index` as superseding document, which is semantically invalid (an index cannot supersede 42 individual topic docs).

---

## Problem

All 42 stale concept/reference files from the PolyTool/ legacy zone had:
- `status: superseded`
- `superseded_by: repo-docs/_index`

This is architecturally incorrect. An index file cannot be the superseding document for 42 specific topic documents. The Phase 2 fix was a bulk placeholder — Phase 3 resolves it properly per-doc.

---

## Decision Criteria

For each file, the question was: **does a dedicated repo-docs document exist that specifically covers this topic?**

- **Yes (strong/clear match):** Update `superseded_by` to the specific repo-docs doc. Add reciprocal `supersedes:` pointer to the repo-docs file.
- **No (no clear match, or issue-tracking content):** Archive the file. Set `status: archived`, `lifecycle: archived`, remove `superseded_by`, move to `claude-memory/archive/research-stale/`.
