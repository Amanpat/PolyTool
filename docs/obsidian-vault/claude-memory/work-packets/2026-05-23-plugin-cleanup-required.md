## Required Actions (Operator — Obsidian Settings UI Only)

### 1. Enable Linter

**Settings > Community Plugins > Browse or toggle**

- Plugin: `Linter` (id: `obsidian-linter`, v1.31.2) — already installed, just needs enabling.
- After enabling, configure: **Settings > Linter**
  - Enable YAML frontmatter rules
  - Disable any rule that rewrites wikilinks (check "Format YAML array" and "YAML Title" rules carefully)

### 2. Enable MetaEdit

**Settings > Community Plugins > Browse or toggle**

- Plugin: `MetaEdit` (id: `metaedit`, v1.8.4) — already installed, just needs enabling.
- No special configuration needed; provides UI panel for editing YAML properties.

### 3. Disable Smart Connections Visualizer

**Settings > Community Plugins > toggle OFF `Smart Connections Visualizer`**

- Spec explicitly excludes Smart Connections: "paywalled, opaque indexing."
- The visualizer is a companion to the main Smart Connections plugin — disabling the visualizer is the minimum action; uninstalling both is preferred.
- The main `smart-connections` plugin folder is present but already not enabled (not in `community-plugins.json`) — no action needed there unless Obsidian auto-enabled it.

### 4. Disable Dataview (unless actively used)

**Settings > Community Plugins > toggle OFF `Dataview`**

- Spec: "superseded by Bases; install only if a specific query case demands it."
- If no active Dataview queries are in use, disable it. Bases provides the same structured-view functionality natively.
